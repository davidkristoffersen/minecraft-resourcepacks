# ThemeLab

The test server's palette, for Minecraft Java 26.2+, **no mods**.

Download: [`ThemeLab-1.0.2.zip`](ThemeLab-1.0.2.zip)

Teal hearts, a cyan experience bar and hotbar frame, and a short digital blip for
every menu click. Derived from the vanilla textures in the installed client jar when
the pack is built; the click is a remap of vanilla sound events - no audio is shipped.
`python3 build.py` builds; shared code lives in `../themelib.py`.
